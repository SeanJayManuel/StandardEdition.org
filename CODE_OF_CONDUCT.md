# Code of conduct

We welcome people with different backgrounds, political views, and levels of experience. Discuss sources, policy, and code through evidence and respectful disagreement.

Expected behavior: be considerate, explain assumptions, accept correction, give useful feedback, and respect privacy. Harassment, threats, discriminatory abuse, sexualized attention, deliberate intimidation, publishing private information, and repeated personal attacks are not acceptable in project spaces.

Sean Manuel, the project maintainer, is responsible for enforcement. For a non-sensitive moderation concern, open an issue requesting moderation without repeating abusive or private material. For a concern requiring privacy, request a private contact without posting the details; use the site's private contact address if one has been published. A dedicated private moderation mailbox is not yet available.

The maintainer may edit or remove content, close a discussion, warn a participant, or restrict participation according to the severity and repetition of the behavior. An affected person may ask for reconsideration with relevant context. Reports and enforcement should disclose only what is necessary. This policy covers repository issues, pull requests, reviews, and other project-managed spaces.
